# Qalbiah — правила проекта

Этот репозиторий содержит, помимо Jekyll-сайта, контент-систему YouTube-канала **Qalbiah**
(исламские истории для англоязычной аудитории). Рабочая папка канала — `qalbiah/`.

## Как работать
- Производство контента запускается через Skill `/qalbiah-production <путь к транскрипции> [shorts|long|both]`.
- Главный агент — координатор: передаёт материалы субагентам из `.claude/agents/`, объединяет результаты,
  сообщает владельцу о спорных фактах. Независимые этапы — параллельно, зависимые — последовательно.
  Не запускать агентов без необходимости.
- Общение с владельцем канала — на русском. Контент для публикации — на английском.

## Постоянные правила Qalbiah (не нарушать)
1. Визуальный стиль — **2D motion** (2D-анимация), драматичная кинематографичная подача, строго по `qalbiah/style-guide.md`.
2. Форматы: Shorts — вертикально 9:16; длинные видео — горизонтально 16:9.
3. Пророки (мир им): никаких различимых черт лица — силуэт, вид со спины, контровой свет, руки, тень, окружение.
4. Не выдумывать религиозные факты, аяты, хадисы, цитаты, номера источников и степени достоверности.
5. Не менять утверждённый стиль канала (`qalbiah/style-guide.md`) без явного разрешения владельца.
6. Английский должен звучать естественно для носителя, а не как машинный перевод.
7. Не придумывать SEO-данные (объёмы поиска, CTR, «гарантированный рост»), не обещать вирусность.
8. Всегда разделять: **[FACT]** факт с источником / **[INTERPRETATION]** толкование / **[RECONSTRUCTION]** художественная реконструкция.
9. Исходные транскрипции неприкосновенны: `qalbiah/input/` только читать; никогда не перезаписывать и не удалять.
   Все результаты — в `qalbiah/projects/<дата>-<slug>/`; правки сохраняются новыми версиями (`-v2`), а не поверх.

## Прочее
- Не удалять и не изменять файлы Jekyll-сайта (`_vendors/`, `_layouts/` и т.д.) в рамках задач Qalbiah.
- `qalbiah/` и `CLAUDE.md` исключены из сборки сайта в `_config.yml`.
