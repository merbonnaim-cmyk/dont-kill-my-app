# Qalbiah Studio

Инструмент для YouTube-канала **Qalbiah**: структура кинематографической исламской истории и промпты для **Seedance 2.5** в вертикальном формате 9:16.

Работает полностью офлайн в браузере: без сервера, платных API и ключей.

## Запуск

Вариант 1 — просто открыть файл `index.html` в браузере (двойной клик).

Вариант 2 — локальный сервер (нужен для открытия с телефона в той же Wi-Fi сети):

```bash
cd qalbiah-studio
python3 -m http.server 8000
# компьютер: http://localhost:8000
# телефон:   http://<IP-компьютера>:8000
```

Также подойдёт любой статический хостинг (GitHub Pages, Netlify и т. п.) — достаточно загрузить четыре файла: `index.html`, `styles.css`, `engine.js`, `app.js`.

## Как пользоваться

1. Введите тему истории (или нажмите на пример).
2. Выберите количество сцен (4–12), место действия, настроение, стиль и длину сцены (5 или 10 с).
3. Если в истории есть пророк, включите переключатель (имя распознаётся автоматически).
4. Нажмите **«Сгенерировать историю»**.
5. Для каждой сцены вы получите: акт (Hook / Развитие / Кульминация / Финал), описание, действие, освещение, движение камеры, промпт Seedance 2.5 и negative prompt.
6. Отредактируйте промпт прямо в поле, скопируйте кнопкой или выгрузите весь проект в `.txt` / `.json`.
7. **«Другой вариант»** — пересобирает сцены с другими визуальными решениями.

Последний проект сохраняется в браузере (localStorage).

## Правила достоверности

- Лицо пророка не показывается: вместо него — мягкое, сдержанное сияние без черт; в negative prompt добавляются запреты.
- Пророк Мухаммад ﷺ не изображается вовсе — только окружение и свет.
- Сподвижники — со спины, в силуэте или вне фокуса; ангелы — только как свет.
- Генератор **не создаёт** аятов, хадисов, имён, дат и событий. Там, где нужны факты, стоит метка `[ПРОВЕРИТЬ]`, а блок «Требует проверки» напоминает сверить всё с Кораном, достоверными хадисами и тафсирами.
- Текст и каллиграфию внутри генерации не используем — аяты добавляйте на монтаже.

## Файлы

- `engine.js` — генератор (шаблоны актов, свет, камера, правила изображения); работает и в Node: `require('./engine.js').generate({ topic: '...', scenes: 6 })`.
- `app.js` — интерфейс.
- `styles.css` — тёмная тема, адаптивная под телефон.
